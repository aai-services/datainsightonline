python is a programming language created by Guido Van Rossum. It is part of the family of interpreted languages, it is very easy to master and offers many advantages:

- python is an interpreted language ;

- it offers a simple syntax ;

- it is portable: the same python code can easily run on several different operating systems ;

-python allows the creation of several types of applications ;

- it allows the creation of websites and companies such as instagram, Nasa... use the python language ;

- moreover python is a powerful tool for data analysis, scientific calculation thanks to famous libraries such as Numpy, pandas, matplotlib, scipy, sklearn, seaborn...

- it is used for computer vision tasks with libraries such as Keras, Tensorflow, Pytorch, onpenCV...;

- Python has a large community in each of the fields in which it is used ;

- It has frequently been in the top 5 programming languages for a few years.
